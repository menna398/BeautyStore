A modern and responsive React.js skincare e-commerce application built to provide a smooth online shopping experience. The project allows users to browse skincare products, filter by category, search for products, manage their shopping cart, and complete the checkout process through a clean and intuitive interface.

---

## 🚀 Live Demo

🔗 **Website:** https://github.com/menna398/BeautyStore.git

---

## 📖 Overview

e-commerce platform designed for skincare enthusiasts. It focuses on delivering a simple, responsive, and user-friendly shopping experience while demonstrating modern front-end development practices and API integration.

The application includes product browsing, shopping cart management and a responsive UI suitable for both desktop and mobile devices.

---

## ✨ Features

* Browse all skincare products
* View product details
* Add and remove products from cart
* Update product quantities
* Checkout page
* Responsive design for all screen sizes
* Toast notifications
* Loading states
* Clean and modern UI

---

## 🛠️ Tech Stack

### Frontend

* React.js
* React Router DOM
* Bootstrap CSS

### Backend / Data

* Dummy API
* Local Storage (Cart Management)
